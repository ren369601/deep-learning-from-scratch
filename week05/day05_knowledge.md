## 1. 先分清优化问题与泛化问题

优化关注“能否把训练目标降下来”；泛化关注“未参与更新的数据表现如何”。

| 观察 | 先考虑什么 |
|---|---|
| 训练 loss 一直很高 | 数据/标签、损失写法、梯度、学习率、模型表达能力 |
| 训练 loss 降，验证 loss 也降 | 当前训练可能有效，继续核对评价 |
| 训练 loss 很低，验证 loss 较高 | 数据分布、泄漏检查、过拟合等 |
| loss 突然出现 NaN 或无穷 | 输入数值、学习率、溢出、非法运算 |

这些是排查方向，不是仅凭一行日志就能下的结论。分类准确率不变也不意味着 loss 没有改善。

神经网络的目标通常不是一个简单的碗形函数。可能有平坦区域、鞍点和不同局部解；换优化器不会保证找到全局最优。

## 2. 一次更新用了多少样本

### 2.1 全批量、单样本与小批量

假设训练集有 100 个样本：

| 方法 | 每次用于求梯度的样本数 | 一轮通常更新几次 |
|---|---:|---:|
| 全批量梯度下降 | 100 | 1 |
| 单样本随机梯度下降 | 1 | 100 |
| 小批量梯度下降，batch_size=20 | 20 | 5 |

一轮 epoch 表示把训练集遍历一遍；一次 step 表示执行一次参数更新。100 轮不总是等于 100 次更新。

如果样本数 N=10，batch_size=4，而且不丢弃末尾样本，那么一轮的三个 batch 大小是 4、4、2。步数是 ceil(N/batch_size)，即向上取整。

PyTorch 的 SGD 是更新算法的名字，实际是全批量、单样本还是小批量，由你给它的 batch 决定。

### 2.2 为什么不用每次都看完整训练集

大数据可能无法一次放进内存；小批量让我们更频繁地更新。小批量梯度是全数据梯度的近似，会有随机波动。较大的 batch 常能降低这类波动，但也增加每次计算成本；不存在所有任务通用的最佳 batch_size。

今天的实验使用固定 batch_size=16，训练样本 64 个，每轮更新 4 次，50 轮共 200 次更新。

### 2.3 DataLoader 在做什么

TensorDataset 把输入和标签配成样本；DataLoader 按 batch_size 分组，并可在每轮打乱顺序。它不负责更新参数。

~~~text
for epoch:
    for X_batch, y_batch in loader:
        清梯度 -> 前向 -> batch loss -> 反向 -> 更新
~~~

shuffle=True 时，同一行输入与标签仍作为一对移动。今天固定打乱的随机生成器，方便不同实验使用相同的样本顺序。

## 3. 学习率：梯度指方向，步长还需你选择

普通 SGD 的简化更新为：

~~~text
theta_new = theta - lr * gradient
~~~

theta 表示参数，gradient 是当前 loss 对参数的导数，lr 是学习率。更新幅度不仅取决于 lr，还取决于梯度大小。

以 L(w)=(w-3)^2、初始 w=1 为例，导数是 2*(w-3)=-4：

| lr | 更新后 w | 更新后 loss | 观察 |
|---:|---:|---:|---|
| 0.1 | 1.4 | 2.56 | 比初始 loss=4 小 |
| 1.0 | 5.0 | 4.00 | 跳到另一侧，误差大小没变 |
| 1.2 | 5.8 | 7.84 | 误差变大 |

对于这个特定函数，继续用 lr=1 会在 1 与 5 之间往返；lr=1.2 会越走越远。这个数值界限不适用于任意神经网络，只用来说明步长的影响。

学习率太小，有限训练预算下进步缓慢；太大可能震荡或发散。模型换了、输入尺度换了、优化器换了，合适的学习率也可能改变。

## 4. 学习率调度：让步长随训练改变

固定学习率便于今天做对照。真实训练中，也可以按预先规定的方案调整：

| 方案 | 直觉或简式 |
|---|---|
| 分段衰减 | 每隔若干轮乘一个小于 1 的系数 |
| 指数衰减 | lr_t = lr_0 * gamma^t |
| 逆时衰减 | lr_t = lr_0 / (1 + a*t) |
| 余弦衰减 | 按余弦曲线平滑地从较大值降到较小值 |
| Warmup | 开始阶段从较小值逐步升到目标学习率 |

t 可以表示轮或步，必须在实验配置中说明。不要给一个模型加调度、另一个固定学习率，却把全部差异归因于优化器。

PyTorch 中常见调用顺序是每轮先执行参数更新，轮末再调用 scheduler.step()。有些调度器按 step 调用，有些根据验证指标调用，要查看具体接口。[优化器与调度说明](https://docs.pytorch.org/docs/2.14/optim.html)

## 5. 动量：除了当前梯度，还记住之前的方向

普通 SGD 只用当前梯度。动量 SGD 用一个累积方向 v，简化写为：

~~~text
v_t = momentum * v_previous + g_t
theta_new = theta - lr * v_t
~~~

假设 momentum=0.9、初始 v=0，两次梯度分别为 2 和 2：

~~~text
第一次：v=2
第二次：v=0.9*2+2=3.8
~~~

方向连续一致时，历史信息积累；方向来回变化时，部分历史信息可能相互抵消。它可能加快某些任务，但也可能过冲，仍需要调学习率。

Nesterov 动量可理解为更早考虑沿动量方向前进后的梯度信息。今天只需认识它与普通动量的区别，不要求手写算法。

## 6. 自适应优化器：每个参数的尺度不一定相同

### 6.1 AdaGrad 与 RMSprop

AdaGrad 累积每个参数过去梯度的平方，并用其平方根调整更新尺度。经常出现大梯度的参数，后续相对步长会被缩小；累计量一直增长也可能导致后期步长过小。

RMSprop 使用梯度平方的指数移动平均，使很久以前的梯度影响逐渐衰减。

### 6.2 Adam 的两个记忆量

Adam 同时记录梯度平均 m 与梯度平方平均 v：

~~~text
m_t = beta1*m_previous + (1-beta1)*g_t
v_t = beta2*v_previous + (1-beta2)*g_t^2
m_hat = m_t / (1-beta1^t)
v_hat = v_t / (1-beta2^t)
theta_new = theta - lr*m_hat/(sqrt(v_hat)+epsilon)
~~~

平方、除法等对每个参数元素分别进行。beta1、beta2 控制历史保留程度；偏差修正补偿初始 m、v 为零带来的影响；epsilon 是防止除零的小数。

第一次更新时，若梯度 g=2、beta1=0.9、beta2=0.999，则 m=0.2、v=0.004，修正后 m_hat=2、v_hat=4。更新幅度约为 lr，而不是普通 SGD 中的 2*lr。

所以“相同学习率”不等于“实际更新幅度相同”。Adam 会自适应缩放更新，但仍需要选择总体学习率。

| 优化器 | 记忆信息 | 今天需要掌握 |
|---|---|---|
| SGD | 当前梯度 | 基础更新方向和步长 |
| Momentum SGD | 历史方向 | 缓和部分震荡与积累方向 |
| AdaGrad | 累计梯度平方 | 参数尺度自适应，可能后期变慢 |
| RMSprop | 近期梯度平方 | 不让累计量无限增长 |
| Adam | 近期方向与梯度平方 | 常用自适应优化方法 |

优化器的表现取决于任务和配置。一次小实验不能证明某种优化器永远最好。

## 7. 输入预处理：特征尺度为何影响优化

假设两个特征数值通常分别在 1 和 1000 附近。即使它们都很重要，数值较大的特征也可能产生很大的参数梯度，让相同学习率下的更新不平衡。

标准化对每一列特征计算：

~~~text
X_standard = (X - mean_train) / std_train
~~~

mean_train、std_train 都只用训练数据估计；验证数据使用同一组数值。不能把训练与验证合起来算统计量，也不能为验证数据重新单独拟合一套统计量。

例：训练某列为 [10,20,30]，均值为 20，除以 N 的标准差约 8.165。验证值 25 转换为 (25-20)/8.165，约 0.612。

train_X.mean(dim=0, keepdim=True) 沿样本维度求各特征均值，结果 shape 为 (1,D)，便于广播到 (N,D)。std 使用 correction=0；若某列几乎不变，用很小的下限避免除零。

输入标准化与明天的 BatchNorm/LayerNorm 不同：这里是用训练数据统计量预处理原始输入。今天的分类标签依然是 0/1，不跟着输入一起标准化。

其他预处理包括处理缺失值、类别编码、图像数值缩放或去均值。所有会从数据估计规则的操作都要注意训练/验证边界；在 K 折实验中须在每折训练部分重新拟合。

## 8. 初始化：模型第一步从哪里开始

单个线性回归层可以从零开始训练；多层网络若把同一层隐藏单元初始化得完全相同，它们可能得到相同输出和梯度，无法学习不同特征。全零 ReLU 网络还可能出现大部分参数没有有效梯度的情况。

随机初始化可以打破对称性，但尺度也重要：太大可能造成激活或梯度过大，太小可能导致信号或梯度逐层衰减。

Xavier（Glorot）初始化考虑输入与输出连接数，常见尺度与 sqrt(2/(fan_in+fan_out)) 有关；Kaiming（He）初始化常用于 ReLU，fan_in 模式的正态分布标准差约为 sqrt(2/fan_in)。

fan_in 是每个输出单元接收的输入数，fan_out 是输出单元数。不是所有激活函数都应套同一种初始化。PyTorch 提供对应接口；不需要手写抽样算法。[初始化说明](https://docs.pytorch.org/docs/2.14/nn.init.html)

今天的对照沿用同一个模型默认初始化和固定 seed。初始化接口在速查里给出作为参考；不要同时改变初始化、优化器和学习率后，只解释其中一个因素。

## 9. 怎样做一个能解释的优化实验

今天固定数据 seed=7、模型 seed=42、batch 打乱 seed=202、batch_size=16、训练轮数=50，并使用同一标准化输入。

第一组：SGD 和 Adam 都使用 lr=0.03，观察在这组固定配置下的差异。它只是固定学习率的对照，不是两个优化器各自调到最好后的竞赛。

第二组：固定 SGD，比较 lr=0.003、0.03、0.3，观察学习率影响。看多轮 train/val loss，不只看最后的准确率。

所有实验都要创建新模型和新优化器；不能让 Adam 接着 SGD 已经训练过的模型继续训练。

每轮结束后，用当前模型在完整训练/验证数据上重新评估。这样日志是同一时刻的指标，且不会把不同大小 batch 的平均损失错误地等权平均。
