## 1. 先分清楚要预测什么

“模型输出是一个数字”不代表任务一定是回归。关键在于这个数字代表什么。

| 任务 | 输入示例 | 希望得到的答案 | 答案的含义 |
|---|---|---|---|
| 回归 | 房屋面积、楼层 | 预计价格 180 | 连续数值 |
| 二分类 | 一封邮件的特征 | 正常 0 / 垃圾 1 | 两个互斥类别 |
| 多分类 | 一张手写数字图 | 类别 0 到 9 | 多个互斥类别 |
| 聚类 | 一批用户的行为特征 | 相似用户分组 | 没有事先给定类别标签 |

回归通常用 MSE 或 MAE 衡量误差；分类可以看准确率，还要选择能用于训练的分类损失。把类别编号 0、1、2 当成普通数值做回归，会额外引入“类别 2 比类别 1 大、离类别 0 更远”这样的数值关系，而这些关系未必符合任务。

监督学习用输入和目标标签学习；无监督学习从无目标标签的数据中寻找结构。强化学习根据行动产生的奖励学习决策，会在课程后面展开。

昨天用“任务、数据、模型、损失、优化、评价”描述一个项目；老师课程的“模型、学习准则、优化算法”是其中的核心学习机制。这两种描述角度可以对应起来。

## 2. 今天的符号表

看到公式前，先认清每个字母代表什么。本文把样本按行放进矩阵。

| 符号 | 含义 | 二分类例子 |
|---|---|---|
| N | 样本数 | 一批 8 个样本 |
| D | 每个样本的特征数 | 每个样本有 2 个特征 |
| C | 类别数（w中的列数）    | 多分类时可能是 3 |
| X | 一批输入 | shape 为 (N, D) |
| w、b | 权重与偏置，训练要更新的参数 | 每个特征一个权重 |
| z | 加权求和得到的原始分数，叫 logit | 可以为负，也可以大于 1 |
| p | 模型给出的概率估计 | 二分类中估计属于类别 1 的概率 |
| y | 正确标签 | 0 或 1 |
| L | 损失，衡量当前预测的错误 | 一个标量 |
| lr | 学习率，控制更新步长 | 例如 0.1 |

大写 X 表示多个样本；小写 x 表示一个样本。下标表示索引，例如 x1 是第一个特征，不是 x 的一次方。

## 3. 线性代数：加权求和怎样变成批量计算

### 3.1 先看一个样本

有两个特征 x=[2, 1]，权重 w=[1, -1]，偏置 b=0.5：

~~~text
z = x1*w1 + x2*w2 + b
  = 2*1 + 1*(-1) + 0.5
  = 1.5
~~~

权重可以理解成特征对分数的影响方向和大小：这里第一个特征增加会提高 z，第二个特征增加会降低 z。这种解释是在其他特征和参数保持不变时成立的。

### 3.2 多个样本一起算

~~~text
X = [[2, 1],       shape (3, 2)
     [0, 1],
     [1, 1]]
w = [[ 1],        shape (2, 1)
     [-1]]

z = X @ w + 0.5   shape (3, 1)
  = [[ 1.5],
     [-0.5],
     [ 0.5]]
~~~

矩阵乘法中间的维度要相等：(3,2) @ (2,1) -> (3,1)。结果每行对应一个样本。

PyTorch 的 nn.Linear(2,1) 内部 weight 存为 (1,2)，因此实现等价于 X @ weight.T + bias。它与上面把 w 存成列向量的写法表达的是同一件事。

### 3.3 范数和逆矩阵在哪里出现

L1 范数是绝对值之和；L2 范数是平方和再开方。例如向量 [3,4] 的 L1 范数是 7，L2 范数是 5。正则化会用它们限制参数大小；后面会系统讲。

方阵 A 的逆矩阵 A_inverse 满足 A @ A_inverse = I，I 是单位矩阵。不是所有方阵都有逆。线性回归有解析解的讨论，但实际计算优先使用稳定的线性方程求解器；今天训练模型仍用梯度下降，不要求手工求逆。

## 4. 微积分：为什么梯度能告诉我们怎么更新

导数描述一个变量略微改变时，函数如何变化。以 L(w)=(w-3)^2 为例：

~~~text
dL/dw = 2*(w-3)
w=1 时：L=4，导数=-4
学习率 lr=0.1：
w_new = w - lr*(dL/dw)
      = 1 - 0.1*(-4)
      = 1.4
新损失 = (1.4-3)^2 = 2.56
~~~

导数为负，说明在当前位置稍微增大 w 会减小 L。更新中减去负数，所以 w 增大。学习率太大可能跳过低损失区域，因此一次更新不保证任意步长下都下降。

多个参数时，对一个参数求导而固定其他参数，叫偏导数；把所有偏导数组成向量，叫梯度。高阶导数则描述导数如何继续变化，例如曲率。

一阶泰勒近似写为：

~~~text
L(w + delta) 约等于 L(w) + (dL/dw)*delta
~~~

它说明：在足够小的邻域里，选择 delta 与导数相反方向，可使近似损失下降。多参数时用梯度的点积代替乘法。这个“局部近似”也解释了为何学习率不能无限大。

链式法则把层层依赖连接起来。若 z 依赖 w，p 依赖 z，L 依赖 p，那么：

~~~text
dL/dw = (dL/dp) * (dp/dz) * (dz/dw)
~~~

Autograd 替你执行这条计算链；它不会替你决定该用哪个损失。

## 5. 概率统计：分类概率代表什么

二分类输出 p 表示模型估计 P(y=1 | x)，读作“给定输入 x，标签是 1 的概率”。类别 0 的概率是 1-p。p=0.8 表示模型给出的估计，并不保证现实中每个这样评分的样本都有精确的 80% 成功率；这涉及校准和数据分布。

与今天有关的分布：

- Bernoulli（伯努利）：一个 0/1 结果，如是否属于类别 1。
- Categorical（类别分布）：从 C 个互斥类别中选一个，每类有一个概率。
- Normal（正态分布）：描述围绕均值波动的连续量；线性回归的一种统计解释会假设目标噪声为正态分布。

概率的基本规则是非负、所有互斥结果的概率之和为 1。条件概率满足 P(A|B)=P(A,B)/P(B)，分母要求非零。

统计量用有限数据描述总体。数据 [1,3,5] 的均值是 3，除以 N 的方差为 ((1-3)^2+(3-3)^2+(5-3)^2)/3=8/3。估计总体方差时还可能采用 N-1 作分母，要说明所用定义。

## 6. 线性回归：直接把分数当成数值预测

线性回归使用 z=x·w+b 直接预测连续目标。单个样本平方误差为 (z-y)^2，一批样本取平均得到 MSE。

如果真实价格为 10，预测为 8，平方误差是 4；预测为 12 也是 4。训练要让这些数值差距减小。

同一个 Linear 层输出 z=2.0，在线性回归中可以解释为“预测数值是 2.0”；若是分类，就需要另一套解释与损失。

## 7. Logistic 回归：从一个分数得到二分类概率

### 7.1 第一步：仍然先算分数

~~~text
z = x·w + b
~~~

z 是任意实数，不能直接叫概率。例如 -2 和 3 都不在概率的取值范围内。

### 7.2 第二步：Sigmoid 把分数映射到 0 到 1

~~~text
p = sigmoid(z) = 1 / (1 + exp(-z))
~~~

exp(a) 表示 e 的 a 次方。无需背 e 的小数值，代码用 torch.sigmoid 即可。

| z | p，约值 | 模型倾向 |
|---:|---:|---|
| -2 | 0.1192 | 类别 0 |
| 0 | 0.5000 | 位于阈值上 |
| 2 | 0.8808 | 类别 1 |

今天约定 p>=0.5 预测类别 1，否则预测 0。由于 Sigmoid 单调，这等价于 z>=0 预测 1。阈值是评价/使用阶段的选择，实际任务可以根据漏报和误报代价调整。

### 7.3 第三步：用二元交叉熵衡量概率

~~~text
单个样本损失：
L = -[y*log(p) + (1-y)*log(1-p)]
~~~

这里 log 是自然对数，y 只能是 0 或 1。拆成两个情况就不难：

- y=1：L=-log(p)，希望 p 越接近 1 越好。
- y=0：L=-log(1-p)，希望 p 越接近 0 越好。

真实类别为 1 时，p=0.8 的损失约 0.2231；p=0.2 的损失约 1.6094。模型给真实类别的概率越小，惩罚越大。

准确率只看阈值后的类别。p 从 0.6 提升到 0.9，两次都预测 1，准确率可能不变，但真实标签为 1 时损失会下降。阈值判断几乎处处没有可用梯度，因此不直接用准确率训练。

### 7.4 第四步：训练直接使用原始分数

PyTorch 的 BCEWithLogitsLoss 合并了 Sigmoid 和二元交叉熵，并采用稳定的数值计算。训练时把 logits z 直接交给它；展示概率时才额外调用 sigmoid。[接口说明](https://docs.pytorch.org/docs/2.14/generated/torch.nn.modules.loss.BCEWithLogitsLoss.html)

~~~text
训练：X -> Linear -> logits -> BCEWithLogitsLoss(logits, y)
预测：X -> Linear -> logits -> Sigmoid -> 概率 -> 阈值类别
~~~

今天统一 logits 与 y 都为 (N,1)，y 是浮点 Tensor，元素为 0.0 或 1.0。这与上一周两输出分类中使用整数类别标签的写法不同。

### 7.5 梯度为什么是 p-y（理解用）

对单个样本，Sigmoid 导数为 p*(1-p)。二元交叉熵对 p 的导数为 (p-y)/(p*(1-p))。链式法则相乘，得到 dL/dz=p-y。

若真实标签 y=1、模型 p=0.2，梯度为 -0.8。优化会倾向于提高这个样本的 z，进而提高 p。一批样本的平均损失还要除以样本数 N：

~~~text
dL/dw = X.T @ (p-y) / N
dL/db = mean(p-y)
~~~

今天不要求手写反向传播，但要能解释梯度的正负方向。

### 7.6 Sigmoid 非线性，分类边界为什么仍是直线

阈值 0.5 对应 z=0，即 x·w+b=0。两个特征时这是直线；更多特征时是超平面。因此，原始特征上的 Logistic 回归仍是线性分类器，不能通过一条直线正确分开 XOR 的四个点。加入非线性特征或多层网络才能改变这个表达限制。

## 8. Softmax 回归：多个类别如何分配概率

三分类时，每个样本得到三个分数 z0、z1、z2，各对应一个类别。Softmax 沿类别维度计算：

~~~text
p_k = exp(z_k) / sum_j exp(z_j)
~~~

分子是第 k 类分数的指数；分母对该样本所有类别求和。例子：

~~~text
logits = [2, 1, 0]
概率约为 [0.6652, 0.2447, 0.0900]
预测类别 = 0
~~~

三项概率之和为 1。若真实标签是 0，交叉熵为 -log(0.6652)，约 0.4076。Softmax 回归使用线性层一次输出 C 个分数；它与更深的分类网络可以使用相同的输出层和损失，但模型表达能力不同。

PyTorch 写法：nn.Linear(D,C) 输出 (N,C) logits；nn.CrossEntropyLoss 接收这些 logits 和 (N,) 的整数类别标签，编号范围为 0 到 C-1。[接口说明](https://docs.pytorch.org/docs/2.14/generated/torch.nn.CrossEntropyLoss.html)

二分类也可以用两个 logits 加 CrossEntropyLoss；今天练习二分类统一使用一个 logit 加 BCEWithLogitsLoss，避免混淆两种标签格式。

## 9. 感知机：根据分错样本调整一条边界

感知机也先计算 z=x·w+b，再根据符号选择类别。它直接使用判别分数，没有 Sigmoid 概率。

为了便于写更新公式，本节标签约定为 -1 和 +1，区别于 Logistic 回归的 0/1 标签。当 y*z<=0 时更新，包含样本恰在边界上的情况：

~~~text
w_new = w + lr*y*x
b_new = b + lr*y
~~~

例：x=[1,2]、y=-1、w=[1,0]、b=0。当前 z=1，倾向 +1，分错了。取 lr=0.1：

~~~text
w_new = [1,0] + 0.1*(-1)*[1,2] = [0.9,-0.2]
b_new = -0.1
新 z = 0.9*1 - 0.2*2 - 0.1 = 0.4
~~~

分数下降了，但仍为正；一次更新不保证立即改对。对于线性可分的有限数据，标准感知机有收敛保证；对 XOR 这样的非线性可分数据，单层感知机无法得到全正确的线性边界。

## 10. 四个模型放在一起看

| 模型 | 模型输出如何解释 | 常用学习准则 | 表达限制 |
|---|---|---|---|
| 线性回归 | 连续预测值 | MSE | 线性/仿射数值关系 |
| Logistic 回归 | Sigmoid 后的二分类概率估计 | 二元交叉熵 | 线性分类边界 |
| Softmax 回归 | 多个互斥类别的概率估计 | 多类交叉熵 | 线性类别分数 |
| 感知机 | 分数符号决定类别 | 边界违反时更新 | 线性分类边界 |

Logistic 回归的名字里虽然有“回归”，但这里解决的是分类任务。模型有没有隐藏层和非线性特征变换，影响它能表达的关系；仅仅替换输出概率函数，不会让线性分类器自动学会 XOR。

## 11. 训练误差为什么不能代替未知数据上的表现

训练集平均损失叫经验风险；从真实数据分布抽样时的平均损失叫期望风险。我们通常不知道真实分布，无法直接算出期望风险，因此用合理划分的数据做训练和评价。

欠拟合表示训练数据也没学好，可能来自模型过简单，也可能来自优化不足。过拟合表示模型抓住训练数据中特有的噪声或细节，泛化表现较差。不能只凭一轮验证波动判断。

偏差描述平均预测与真实关系的偏离；方差描述换一份训练数据时预测的变化。平方误差中可以分析偏差、方差和不可约噪声，但这套分解不能原样套到所有损失。本周后面会用对照实验理解模型选择和正则化。

验证集用来选择超参数，测试集用来做最后的独立评价。今天的小型合成数据用于检查实现，准确率高不等于在现实数据上已可靠。
