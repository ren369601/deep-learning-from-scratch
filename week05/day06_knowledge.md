# Week 5 / Day 6：归一化、过拟合与正则化

今天完成老师[第 5 讲](https://rmcong.github.io/DL%20Course%202022/chapter5.pdf)后半部分及实验 2 中的模型调优内容。建议用时 2-2.5 小时；先看第 1-7 节并做练习，第 8-9 节用于理解课程其余方法。

核心问题：**训练误差继续变小，为什么验证误差可能反而变大？**

## 1. 训练数据同时包含规律与偶然细节

假设真实关系是 y=sin(2*x)，观测标签还包含随机噪声。训练时看到的是“规律加噪声”，不知道哪一部分是噪声。

容量较大的模型可以拟合越来越多训练细节，但另一些样本的噪声不同。记住训练噪声，未必能帮助预测新样本。

| 情况 | 训练表现 | 验证表现 | 需要考虑 |
|---|---|---|---|
| 欠拟合 | 较差 | 较差 | 模型表达不足、训练不足、数据或目标问题 |
| 较合理拟合 | 逐步改善 | 也改善 | 持续检查是否稳定 |
| 可能过拟合 | 继续改善 | 持续变差或明显落后 | 噪声、样本量、容量与正则化 |

训练与验证误差不同并不自动证明过拟合，要检查分布差异、计算方式和波动。明天复习时要能把“优化困难”和“泛化问题”分开解释。

## 2. 三种归一化操作的区别

### 2.1 输入标准化

昨天用训练数据计算各列均值和标准差，再处理训练及验证输入。这是原始数据预处理。

### 2.2 BatchNorm：同一特征跨样本计算

对表格形状 (N,H) 的隐藏特征，BatchNorm1d(H) 在训练时沿样本维度计算每个特征的统计量：

~~~text
z_normalized = (z - mean_batch) / sqrt(var_batch + epsilon)
output = gamma * z_normalized + beta
~~~

epsilon 防止分母为零；gamma、beta 是可学习的缩放与平移。归一化后模型仍可以学习适合的输出尺度。

例：三个样本的一个隐藏特征为 [1,3,5]，均值为 3，除以 N 的方差是 8/3。归一化后约为 [-1.225,0,1.225]（忽略很小的 epsilon）。

默认设置下，训练模式更新运行均值/方差，评估模式使用保存的运行统计量。PyTorch 前向归一化用有偏方差，更新运行方差采用无偏估计；不必手算这些内部细节，但要知道训练/评估行为不同。[BatchNorm1d 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.BatchNorm1d.html)

如果验证时只用 no_grad，却仍处于 train 模式，BatchNorm 可能继续用验证 batch 并更新统计量。因此验证要配合 model.eval()。

### 2.3 LayerNorm：每个样本内部计算

LayerNorm(H) 对 (N,H) 中每一行的 H 个特征计算统计量。一个样本的归一化不需要依赖其他样本，默认也没有 BatchNorm 那样的运行均值/方差。

~~~text
Z = [[1,  2],
     [3,  6],
     [5, 10]]

BatchNorm：分别看列 [1,3,5] 和 [2,6,10]
LayerNorm：分别看行 [1,2]、[3,6]、[5,10]
~~~

本页约定样本按行存放。阅读其他讲义时，如果数据排布不同，“按行/按列”的说法可能反过来，真正要看的是样本维和特征维。

### 2.4 Weight Normalization：改变权重参数化

权重归一化把一个权重向量表示为 w=g*v/||v||，把大小 g 与方向 v 分开学习。它不是对 batch 激活求均值/方差，不能与前两种视为同一个操作。

归一化层可以改变优化条件，但不能保证消除所有梯度问题或提升泛化。BatchNorm、LayerNorm、权重归一化应结合网络结构和输入情况选择。

## 3. 正则化：限制某些拟合方式

正则化是为了改善泛化，对参数、结构、训练过程或数据施加额外约束。一个正则化模型的训练误差较高、验证误差较低，可能是合理结果。

### 3.1 L2 惩罚

采用以下系数约定：

~~~text
total_loss = data_loss + (lambda/2) * sum(w^2)
对参数的额外梯度 = lambda*w
~~~

参数越大，惩罚越大。普通无动量 SGD 的更新可写成：

~~~text
w_new = (1-lr*lambda)*w - lr*data_gradient
~~~

这时可以理解为先让权重缩小一点，再进行数据梯度更新。lambda 越大并不一定越好，太大可能欠拟合。

### 3.2 L1 惩罚

L1 使用 lambda*sum(abs(w))，往往更倾向于稀疏参数。普通有限步数梯度训练不保证所有小权重变为精确的零，要区分这个倾向与具体求解算法。

### 3.3 AdamW 的权重衰减

AdamW 把权重衰减与自适应梯度更新分开处理。对 Adam 把 L2 加进 loss，与 AdamW 的解耦权重衰减并不一般等价。[AdamW 文档](https://docs.pytorch.org/docs/2.14/generated/torch.optim.AdamW.html)

今天所有对照都用 AdamW：基线明确设 weight_decay=0.0，权重衰减组用 0.03。此教学例子衰减全部注册参数；真实项目可能单独排除偏置和归一化参数，要说明规则。

日志统一报告未加惩罚项的 MSE，才能直接比较各组的预测误差。

## 4. Dropout：训练时随机屏蔽一部分激活

Dropout(p) 的 p 是丢弃概率。训练时，保留下来的激活乘以 1/(1-p)，被丢弃的置零；评估时直接通过输入。[Dropout 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Dropout.html)

例如输入 [2,4,6,8]，p=0.5，一次随机掩码可能保留第 1、3 项，输出 [4,0,12,0]。下一次可能换一组保留位置。

缩放使单个激活的期望保持原值，不保证每次输出均值都完全不变，也不保证非线性网络的最终预测期望不变。

它可以减少对某些激活组合的依赖，但 p 太大可能妨碍学习。Dropout 没有永久删掉神经元或参数；model.eval() 时会关闭随机屏蔽。

今天对训练集和验证集报告误差时都用 eval 模式，避免把“Dropout 开启时的训练 loss”与“关闭时的验证 loss”混为同一种评价。

## 5. 早停：保存最好的一次，而不是只停下来

早停监控验证指标，当一段时间没有足够改善时停止训练。

| 概念 | 含义 |
|---|---|
| best_loss | 目前记录到的最佳验证 loss |
| min_delta | 多大改善才算值得更新最佳记录 |
| patience | 连续多少轮无足够改善才停止 |
| best_state | 最佳记录对应的参数快照 |

例：验证 loss 依次为 0.8、0.6、0.55、0.56、0.58。设 min_delta=0.005、patience=2，前 3 轮依次改善，第 4、5 轮连续无改善，第 5 轮停止，恢复第 3 轮参数。

不能只保存 best_state=model.state_dict() 后继续训练，因为字典里的 Tensor 可能仍引用模型存储；要用 deepcopy 或逐个 clone 作快照。最后调用 load_state_dict 恢复。

验证数据没有参与 backward，但它通过选训练时点影响最终模型。因此最佳验证 loss 仍然不是独立测试成绩。

今天“最佳”指满足 min_delta 判定的记录；未超过 min_delta 的微小下降不会更新检查点。保存这个约定可以避免理解上的歧义。

## 6. 超参数怎样选

学习率、宽度、Dropout 概率、权重衰减系数、patience 都是超参数。它们不由普通参数梯度直接统一决定。

| 方法 | 思想 |
|---|---|
| 网格搜索 | 枚举预先列出的组合 |
| 随机搜索 | 在候选范围抽取组合 |
| 贝叶斯优化 | 根据已有实验建立预测，选择下一组配置 |
| 动态资源分配 | 提早终止部分较差配置，把预算留给其他候选 |
| 神经架构搜索 | 把部分网络结构选择也作为搜索对象 |

两种学习率乘三种 Dropout 概率就有六个组合。搜索预算也要写清楚；尝试越多配置越可能偶然迎合验证集。

今天预先固定四个方案，只作小实验比较。后续综合实验会先选配置，再用独立测试数据验收。

## 7. 数据增强与其他解决方向

数据增强对样本施加尽量保持任务标签的变换，如某些图像翻转、裁剪等。变换是否合理依赖任务：翻转普通物体图像可能可行，翻转某些字符却可能改变类别或含义。

还可以收集更多可靠数据、减小容量、修正标签等。正则化不能把错误的数据定义自动变成正确的研究任务。

## 8. 本讲其余方法速查

以下补齐前一天尚未细讲的课程方法，先理解用途，暂不增加大型实现：

- 梯度截断：backward 后、step 前限制梯度的值或整体范数，用于控制过大更新；它不会修复错误标签或 NaN 的根本原因。
- 牛顿法：利用二阶曲率求更新方向，典型形式为解 H*delta=-g。H 是 Hessian；大网络构造和求解成本高，不等于直接在代码里求逆就更好。
- 周期性学习率：按预设周期升降学习率，区别于一直衰减。
- 正交初始化：让权重矩阵具有适当正交结构；预训练初始化：从已学参数开始适配，而不是重新随机抽样。
- PCA 白化：改变特征坐标并按方差缩放以减少相关性；ZCA 白化再映回原坐标方向。统计量只从训练部分拟合，微小特征值需稳定处理；它不是所有数据都必须采用的预处理。

## 9. 今天的实验与验收

使用 16 个带噪声训练样本、128 个独立同分布验证样本，学习一维非线性回归。MLP 容量相对训练样本较大，便于观察训练与验证的差距。

四组对照：无额外正则化、Dropout(p=0.3)、AdamW 权重衰减(0.03)、早停(patience=25)。都从同一初始参数、同一数据开始，学习率 0.01，最多 400 轮。Dropout 自身会引入额外随机性。

训练函数已提供。你完成 Dropout 模式练习、早停计数练习，以及四组结果的汇总。不要预先假定每一种方法都提高验证成绩；先记录实际结果，再解释其边界。

能够解释 train/eval 的变化、区分 BN/LN 的归一化维度、读懂训练与验证误差、保存和恢复检查点，就达到今天的主要目标。
