# Week 1 / Day 5：线性回归雏形与误差

前四天，我们能让模型根据输入给出预测：

```text
prediction = w * x + b
```

但一个新问题出现了：

```text
模型预测得好不好，怎么判断？
```

今天的答案是：把预测值与真实答案比较，计算误差。

## 1. 什么是数据集？

假设真实规律是：

```text
y = 2x + 1
```

我们准备几组已知答案的数据：

```python
xs = [1, 2, 3, 4]
ys = [3, 5, 7, 9]
```

其中：

```text
x：输入特征。
y：真实答案，也叫 label（标签）或 target（目标值）。
```

它们按位置一一对应：

```text
x = 1 -> 真实 y = 3
x = 2 -> 真实 y = 5
x = 3 -> 真实 y = 7
x = 4 -> 真实 y = 9
```

## 2. 什么是误差？

如果模型参数是：

```text
w = 1
b = 0
```

模型预测：

```text
x = 3 -> prediction = 1 * 3 + 0 = 3
```

而真实答案是：

```text
target = 7
```

两者的差：

```text
prediction - target = 3 - 7 = -4
```

这就是误差。负号表示预测偏小，正号表示预测偏大。

## 3. 为什么用平方误差？

直接把误差相加会有问题：正误差和负误差可能互相抵消。

所以常用平方误差：

```text
square error = (prediction - target)^2
```

例子：

```text
prediction = 3
target = 7

square error = (3 - 7)^2 = 16
```

平方后一定不小于 0，预测越离谱，结果越大。

## 4. MSE：平均平方误差

一个数据集有多个样本，因此我们计算每个样本的平方误差，再求平均：

```text
MSE = 所有平方误差的平均值
```

完整公式是：

```text
MSE = ((p1 - y1)^2 + (p2 - y2)^2 + ... + (pn - yn)^2) / n
```

其中：

```text
p：模型预测值 prediction。
y：真实答案 target。
n：样本数量。
```

在深度学习中，MSE 是一种 loss function（损失函数）。

最重要的判断标准：

```text
loss 越小，模型预测通常越好。
```

## 5. 今天如何寻找更好的参数？

今天还不会自动求梯度，所以使用最朴素的方法：

```text
尝试几组 w 和 b
-> 每组都计算 MSE
-> 选出 MSE 最小的一组
```

例如：

```text
w = 1, b = 0 -> MSE 较大
w = 2, b = 1 -> MSE = 0
w = 3, b = 0 -> MSE 较大
```

对于 `y = 2x + 1` 这组数据，`w = 2, b = 1` 是完美参数。

这叫作枚举或暴力搜索。它在真实深度学习中太慢，不能直接使用；但它能清楚说明训练的目标：

```text
寻找使 loss 更小的参数。
```

Week 2 我们会学习梯度下降，让参数自动向更好的方向移动。

## 6. 今天要形成的直觉

```text
数据集 = 输入 x + 真实答案 y。
模型 = 用当前参数从 x 算出 prediction。
loss = prediction 与 y 的差距。
训练目标 = 调整参数，让 loss 变小。
```

```text
dataset：数据集
label / target：真实答案、标签、目标值
prediction：预测值
error：误差
loss：损失

```
