# Week 1 / Day 1：线性模型入门

## 1. 什么是模型？

深度学习里经常说“模型”，你可以先把它理解成：

```text
一个输入 x 进去，经过某种计算，输出一个预测 y。
```

最简单的模型就是：

```text
y = w * x + b
```

这叫线性模型。

比如：

```text
w = 2
b = 1
x = 3
```

那么：

```text
y = 2 * 3 + 1 = 7
```

## 2. 每个符号是什么意思？

```text
x：输入数据
w：权重，决定 x 的影响有多大
b：偏置，负责整体平移
y：模型输出，也就是预测结果
```

你可以先这样记：

```text
模型 = 一种计算规则
参数 = w 和 b
输入 = x
输出 = y
学习 = 调整参数，让 y 更接近真实答案
```

## 3. 一个现实例子

假设我们想预测一个学生的考试分数，只看学习小时数：

```text
分数 = w * 学习小时数 + b
```

如果：

```text
w = 10
b = 30
```

那就表示：

```text
每多学习 1 小时，预测分数增加 10 分
基础分是 30 分
```

所以：

```text
学习 5 小时 → 10 * 5 + 30 = 80 分
```

这就是模型在做预测。

## 4. 为什么这和深度学习有关？

以后你会看到神经网络里有一层叫：

```python
nn.Linear(...)
```

它本质上也是：

```text
y = wx + b
```

只不过今天我们处理的是一个数字：

```text
x = 3
```

以后会变成很多数字组成的向量或矩阵：

```text
x = [0.2, 1.5, -0.7, 3.1]
```

再往后，图片、文本、语音都会先变成数字，然后进入模型。

所以深度学习不是魔法，它的底层一直在做：

```text
输入数字
→ 用参数计算
→ 得到预测
→ 计算预测错了多少
→ 调整参数
```

今天先只学第一步：

```text
输入数字 → 用 w 和 b 算出 y
```

## 5. 为什么 w 和 b 重要？

比如还是预测分数：

```text
y = w * x + b
```

如果：

```text
w = 10
b = 30
```

学习 5 小时预测 80 分。

但如果：

```text
w = 5
b = 40
```

学习 5 小时预测：

```text
5 * 5 + 40 = 65
```

你会发现，同样的输入 `x = 5`，只要 `w` 和 `b` 不同，预测结果就不同。

所以模型学习的过程，本质上就是：

```text
找到合适的 w 和 b，让预测更接近真实答案。
```

这句话非常重要。

以后神经网络里有成千上万个参数，本质上也是在学习一堆类似 `w` 和 `b` 的东西。

## 6. 今天要形成的直觉

今天不需要知道反向传播，也不需要知道 PyTorch。

只要记住：

```text
模型 = 一种计算规则
参数 = w 和 b
输入 = x
输出 = y
学习 = 调整参数，让 y 更接近真实答案
```

一个最小例子：

```python
def linear(x, w, b):
    return w * x + b
```

这个函数就是一个小模型。

当你写：

```python
linear(3, 2, 1)
```

意思是：

```text
输入 x = 3
权重 w = 2
偏置 b = 1
输出 y = 7
```

今天写的代码不是普通 Python 练习，它是在写深度学习里最小、最原始的“模型”。
