## 2. 先区分三个容易混的数量

假设张量形状是 `(2, 6, 28, 28)`。

- 2：一次处理两张图，称为批量大小。
- 6：每张图有六张特征图，称为通道数。
- 28×28：每张特征图的空间大小。

这个张量有 `2×6×28×28=9408` 个数，但这不是网络的参数量。它是这一批输入产生的中间结果，也叫激活值。换一批输入，中间结果会改变。

卷积层的参数则是可学习的权重与偏置；它们被所有样本、空间位置共享。换一批输入，不会重新创建一套参数。

例如 `Conv2d(1, 6, 5)`：

```text
每个输出通道需要：1×5×5=25 个权重，加 1 个偏置
总共 6 个输出通道：6×(25+1)=156 个参数
```

别把输出中的 9408 个数算进这 156 个参数。

## 3. LeNet：先提取特征，再分类

LeNet 是早期用于字符识别的经典卷积网络。今天写的是受 LeNet 启发的教学版，不是逐项复现原始 LeNet-5：我们使用 ReLU、普通平均池化、全连接输出；原版还涉及不同激活、可训练子采样和部分连接等设计。

给网络输入两张 32×32 灰度图。类别数设为 10。

```text
输入                     (2, 1, 32, 32)
5×5卷积，输出6通道        (2, 6, 28, 28)
ReLU                     (2, 6, 28, 28)
2×2平均池化，步长2        (2, 6, 14, 14)
5×5卷积，输出16通道       (2,16, 10, 10)
ReLU                     (2,16, 10, 10)
2×2平均池化，步长2        (2,16,  5,  5)
展平                     (2,400)
全连接400→120，ReLU       (2,120)
全连接120→84，ReLU        (2,84)
全连接84→10              (2,10)
```

为什么第一层从 32 变成 28？没有填充，5 格长的核从起点 0 滑到起点 27，共 28 个合法起点，即 `32-5+1=28`。

为什么展平是 400？进入展平的是每张图 16 张 5×5 特征图，所以 `16×5×5=400`。批量大小 2 不能乘进每张图的特征数；`Flatten(1)` 正是保留批量维，从第 1 维开始合并。

你应能口述：卷积把局部模式转成特征通道，池化降低空间大小；后面的全连接层根据这些特征给出类别分数。不要机械地认为每个通道都对应一个确定的人类概念。

### 参数量完整核对

默认卷积和全连接层都带偏置。ReLU、普通平均池化、展平不含可学习参数。

| 层 | 计算 | 参数量 |
|---|---|---|
| 卷积1 | 6×(1×5×5+1) | 156 |
| 卷积2 | 16×(6×5×5+1) | 2416 |
| 全连接1 | 400×120+120 | 48120 |
| 全连接2 | 120×84+84 | 10164 |
| 全连接3 | 84×10+10 | 850 |
| 总计 | 上述五项相加 | 61706 |

检查点：哪一层参数最多？答案是第一个全连接层，而不是第二个卷积层。空间尺寸虽小，展平后仍会有很多输入连接。

## 4. AlexNet：把 CNN 用到更复杂的图像分类

AlexNet 的重要性不在于“卷积这种运算刚被发明”，而在于它结合更大规模的数据、网络和 GPU 计算，推动了大规模图像分类的发展。其代表性设计包括 ReLU、Dropout 和数据增强；原论文网络有五个卷积层，后接分类部分。

先和已经学过的概念连接：

- ReLU：让层之间不是单纯线性叠加，也便于优化。
- Dropout：训练时随机屏蔽部分激活，缓解过拟合；验证时要切换 `eval()`。
- 数据增强：对训练图像做保持标签意义的变化，不是凭空生成新标签。
- GPU：加快计算，不是改变损失函数或反向传播规则。

原论文涉及双 GPU 通道分组、局部响应归一化等细节，今天不复现整网。不要把今天的尺寸示例当作原论文结构的逐层复制。

### 大图第一层的尺寸例子

这里明确采用输入 224×224、核 11、步长 4、填充 2 的演示配置：

```text
输出边长 = 向下取整((224+2×2-11)/4)+1
         = 向下取整(217/4)+1
         = 54+1 = 55
```

RGB 输入有 3 通道，若输出 64 通道，则参数量为：

```text
64×(3×11×11+1)=23296
```

步长变大让特征图更快缩小，但也可能丢失细节，不是越大越好。64 是本示例选择；历史论文和不同实现的通道数、输入预处理可能不同。

## 5. 从串行网络走到分支网络

串行结构只有一条路线：`输入 → 卷积 → 卷积 → 输出`。

但对同一张图，有的模式范围很小，有的范围较大。一个想法是让同一个输入同时经过不同大小的卷积，再把结果合起来。这就是今天理解 Inception 的入口。

“并行分支”指网络的数据依赖关系；不保证程序执行时所有分支真的在硬件上同时运行。

## 6. Inception：同一个输入，四条特征提取路线

下面是一个小型 Inception 风格模块，不是完整 GoogLeNet，也不是逐参数复现论文。

```text
输入 (2,8,16,16)
  ├─ 1×1卷积：8→4                         → (2,4,16,16)
  ├─ 1×1卷积：8→4 → 3×3卷积：4→6          → (2,6,16,16)
  ├─ 1×1卷积：8→2 → 5×5卷积：2→2          → (2,2,16,16)
  └─ 3×3最大池化 → 1×1卷积：8→4            → (2,4,16,16)
                       沿通道拼接
                       (2,16,16,16)
```

每条分支都读完整的同一个输入，不是把 8 个输入通道平均分成四份。

3×3 卷积用填充 1，5×5 卷积用填充 2，池化用核 3、步长 1、填充 1。这样都保留 16×16 的空间大小，才能沿通道拼接。

最后通道数为什么是 16？因为 `4+6+2+4=16`。批量和高宽不变。

## 7. 拼接不是相加

假设两个分支分别输出 `(2,4,16,16)` 和 `(2,6,16,16)`。

`torch.cat([a,b], dim=1)` 输出 `(2,10,16,16)`：把两组通道接到一起。

`a+b` 在这里不能相加，因为通道数 4 和 6 不匹配。即使两者通道数相同，相加也是把对应位置的数求和，不会增加通道。

检查点：四个分支高宽有一个变成 8×8，还能直接沿通道拼接吗？不能。除拼接维以外的各维都必须一致。

明天的残差网络会使用相加；今天先把拼接理解清楚。

## 8. 1×1 卷积为什么有用

1×1 不是只看“一个数”：当输入有多个通道时，它在一个空间位置同时读取所有输入通道。

假设某个位置的三个通道数是 `[2,3,5]`，一个输出通道的权重是 `[1,0,-1]`，偏置是 0：

```text
输出 = 1×2 + 0×3 + (-1)×5 = -3
```

如果另一个输出通道使用 `[0,1,1]`，输出就是 8。因此 1×1 卷积可把该位置的 3 通道变成 2 通道。它做的是通道混合，没有直接混合邻近空间位置。

### 先降通道，再做大核卷积

为突出权重成本，下面都忽略偏置。

直接用 3×3 卷积从 192 通道变为 128 通道：

```text
128×192×3×3 = 221184 个权重
```

先用 1×1 把 192 通道变成 32，再用 3×3 把 32 变成 128：

```text
降通道：32×192×1×1 = 6144
大核：128×32×3×3 = 36864
合计：43008 个权重
```

输出通道仍是 128，但中间用更窄的表示节约参数和乘加计算。降通道可能损失信息，而且有无中间激活也影响表达能力；两种结构不是数学上完全等价的替换。

参数量不是运行时间：实际速度还取决于特征图大小、访存、硬件和算子实现。

## 9. 怎样把模块变成分类器

今天作业的数据流：

```text
输入 (2,3,16,16)
3×3卷积，填充1，3→8，ReLU
小型Inception模块，8→16
自适应全局平均池化 → (2,16,1,1)
展平 → (2,16)
全连接16→3 → (2,3)
```

全局平均池化把每个通道的所有空间位置取平均。例如一个通道只有 `[[1,3],[5,7]]`，它的平均值就是 4。16 个通道分别取平均，留下 16 个数，不是所有通道一起只剩一个数。

`AdaptiveAvgPool2d((1,1))` 自动选择池化方式，使空间输出为 1×1；它不增加可学习参数。

最终输出是三个原始类别分数。训练配 `CrossEntropyLoss` 时不要先加 Softmax。今天只验证前向和损失计算，不把随机输入的输出当作分类能力。
