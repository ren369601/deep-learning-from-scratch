## 1. 为什么还要改变网络结构

昨天 Inception 通过多条分支提取不同尺度的特征。今天关注另一个问题：网络堆得更深之后，如何让它更容易优化？

先区别两个现象：

- 训练表现好、验证表现差，可能涉及过拟合。
- 更深网络反而连训练误差都更高，不能单纯解释为过拟合，也可能是优化更困难。

原始 ResNet 工作提出学习相对于输入的残差函数，帮助训练深层网络。今天只写小型教学网络，不是 ResNet-18 或论文指标的复现。

## 2. 残差：先保留原值，再学习修正量

先不用图像，假设输入是 3，希望输出是 3.2。

普通分支直接学习 `H(3)=3.2`。残差分支改为学习 `F(3)=0.2`，最后输出 `3+0.2=3.2`。

符号逐个解释：

- `x`：进入这一块的特征，不一定是原始图片。
- `H(x)`：这一块希望实现的映射。
- `F(x)`：卷积主分支产生的修正量。
- `x+F(x)`：原特征与修正量逐位置相加。

所谓“残差”不是分类标签减预测值，也不是损失函数。在这里它指相对于输入的修正表示。

“先保留”是理解数据流的说法，不意味着最后输出永远原封不动保留输入；修正量和后续激活都会改变结果。

## 3. 一块网络，两条路线

今天采用带块后激活的两卷积教学结构：

```text
                 主分支：卷积 → 归一化 → ReLU → 卷积 → 归一化
输入 x ────────┬───────────────────────────────────────────┐
               └──────── 捷径：直接传递或投影 ──────────────┤ 相加 → ReLU
```

主分支是 `F(x)`，捷径同形状时是 `x`。代码是：

```python
features = self.main(images)
shortcut = self.shortcut(images)
output = self.relu(features + shortcut)
```

每个位置相加。例如输入 `[-2,3]`，修正量 `[0.5,-1]`，相加得 `[-1.5,2]`，再过 ReLU 得 `[0,2]`。

这不是把输入与主分支沿通道拼接。昨天 Inception 的拼接增加通道；今天相加不增加通道。

## 4. 修正量为零，整个块一定等于输入吗

必须说明观察的是哪一步。

```text
相加前：主分支为 0
相加后、激活前：x+0=x
整个块：ReLU(x)
```

若输入有负数，ReLU 会把它变成 0，所以整个块不一定恒等。若输入非负，则这时整个块确实等于输入。

今天练习 2 特意放了负数，避免记成“主分支零输出就永远原样返回”。残差网络还有其他激活位置的变体，今天不混在一起学习。

## 5. 相加的两条路线必须对齐

情况一：输入 `(2,8,8,8)`，主分支两次 3×3 卷积都采用步长 1、填充 1，输出仍为 `(2,8,8,8)`。捷径可使用 `nn.Identity()`，不改变数据，也没有参数。

情况二：输入 `(2,8,9,9)`，需要输出通道 16，第一层步长 2。

```text
主分支第一层：8→16，3×3，步长2，填充1
输出边长 = 向下取整((9+2-3)/2)+1 = 5
第二层：16→16，3×3，步长1，填充1
主分支结果：(2,16,5,5)
```

这时输入不能直接相加。捷径使用 `1×1` 卷积，通道 8→16，步长 2：

```text
捷径输出边长 = 向下取整((9-1)/2)+1 = 5
捷径结果：(2,16,5,5)
```

两条路线现在才能逐位置相加。捷径上的可学习转换叫投影，这里还接了归一化层。

检查点：9 经步长 2 后为什么是 5 而不是 4？因为必须代入核大小和填充，而不是直接做 `9//2`。

PyTorch 支持广播，有时错误形状也能相加；残差实现中主动断言形状完全一致，能避免误用广播。

## 6. 为什么卷积后面有 BatchNorm

`BatchNorm2d(C)` 在训练时按通道统计当前批次与空间位置的均值、方差，再归一化，并学习每通道的缩放与平移。它还有用于评估的运行统计。

例如 C=8 时，默认可学习参数是 8 个缩放值与 8 个平移值，共 16 个。运行均值与方差属于缓冲区，不计入可学习参数。

卷积紧接归一化层时，这份代码使用 `bias=False`，避免添加通常不必要的卷积偏置。评估调用 `eval()`，让归一化使用运行统计，而不是临时验证批次的统计。

不要认为 BatchNorm 是残差相加本身：它是主分支和投影分支的组成层；真正的残差连接仍是两条路线的加法。

## 7. 梯度通路：多出来的 1 是什么

先忽略块后 ReLU，使用标量解释：`y=x+F(x)`。

当 x 改变一点点，y 会收到两种变化：直接路径的 x 改变，以及 F(x) 随之改变。因此：

```text
dy/dx = 1 + dF/dx
```

例子 `F(x)=0.1x`：普通路径导数为 0.1，带捷径的导数为 1.1。若后续损失对 y 的导数是 2，传回 x 的梯度分别是 0.2 与 2.2。

代码示例令输出本身反向传播，所以相当于上游导数为 1，看到的梯度就是 0.1 和 1.1。

图像张量的对应表达涉及单位映射与雅可比矩阵；不要把标量的 1 当作给张量中每项梯度都机械加 1。

限制也要记住：块后 ReLU 可能截断梯度，投影捷径不再是恒等映射，主分支导数也可能与捷径贡献抵消。残差连接有助于优化，但不能保证梯度永不消失、永不爆炸。

## 8. 读懂今天的完整网络

```text
输入：(N,1,8,8)
起始卷积1→8 + BatchNorm + ReLU：(N,8,8,8)
三个块，每块两个卷积，始终8通道：(N,8,8,8)
全局平均池化：(N,8,1,1)
展平：(N,8)
全连接8→2：(N,2)
```

普通网络与残差网络都用这些层。普通网络每块只执行 `ReLU(F(x))`；残差网络执行 `ReLU(F(x)+x)`。对照中的所有捷径是无参数的恒等映射。

参数量可以完整核对：

| 部分 | 计算 | 参数量 |
|---|---|---|
| 起始卷积与归一化 | 8×1×3×3+2×8 | 88 |
| 每个块 | 2×(8×8×3×3+2×8) | 1184 |
| 三个块 | 3×1184 | 3552 |
| 分类层 | 8×2+2 | 18 |
| 总计 | 88+3552+18 | 3658 |

两组参数量相同，但前向运算不同；相加增加少量运算，不增加可学习参数。练习 1 另外演示的投影捷径则会增加参数，不要与这个对照混淆。

可能出现两组都接近满分：任务过于简单，准确率不足以区分结构；也可能某一组在某个种子表现较差，必须如实保留。
