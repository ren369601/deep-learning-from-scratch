## 1. 知识讲解：一次训练经过什么

令 `N` 为样本数，`D` 为输入特征数，`H` 为隐藏层宽度，`C` 为类别数。前向传播：

```text
X (N, D)
  -> Z1 = X @ W1 + b1       (N, H)
  -> A1 = ReLU(Z1)          (N, H)
  -> Z2 = A1 @ W2 + b2      (N, C)，也叫 logits
  -> P = Softmax(Z2)        (N, C)
  -> L = mean(-log(P[每个样本, 正确类别]))
```

Softmax 把每行 logits 变成概率；Cross Entropy 衡量正确类别的概率。Accuracy 是分类正确的比例，便于观察，但训练时更新参数依靠 loss 的梯度。

反向传播从 loss 往回走：

```text
dZ2 = (P - one_hot(targets)) / N
dW2 = A1.T @ dZ2
db2 = dZ2.sum(axis=0)
dA1 = dZ2 @ W2.T
dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)
```

这里 `/ N` 只出现一次，因为 loss 是批量平均值。ReLU 在 `Z1 <= 0` 时的导数，本周约定为 0。先计算完所有梯度，再更新四组参数，避免反向传播混用新旧参数：

```text
W1 -= learning_rate * dW1
b1 -= learning_rate * db1
W2 -= learning_rate * dW2
b2 -= learning_rate * db2
```

这就是 `forward -> loss -> backward -> update`。下一周 PyTorch 会替你计算梯度，但这个顺序不变。

## 2. 示例：只用 shape 验证公式

假设 `N=4, D=2, H=8, C=2`。第二层有 `A1 (4, 8)`、`dZ2 (4, 2)`，所以：

```text
dW2 = A1.T @ dZ2 = (8, 4) @ (4, 2) = (8, 2)
```

它与 `W2.shape == (8, 2)` 相同。每个参数的梯度都必须与参数 shape 一致。

## 5. 复盘答案与实验记录

以下是参考答案与运行记录。先自己说一遍，再对照检查；答案写在这里不代表已经掌握。

**练习 1 的 shape：** `Z1 (5, 4)`、`A1 (5, 4)`、`Z2 (5, 2)`、`P (5, 2)`、`dZ2 (5, 2)`、`dW1 (3, 4)`、`db1 (4,)`、`dW2 (4, 2)`、`db2 (2,)`。

**练习 2：** ReLU 提供非线性。若去掉它，两层线性（含偏置）可以合并为一层仿射变换：`(X @ W1 + b1) @ W2 + b2 = X @ (W1 @ W2) + (b1 @ W2 + b2)`。因此无法表达 XOR 这样的非线性关系。

**练习 3：** 本轮的所有梯度必须对应同一次前向传播所用的参数。`dA1 = dZ2 @ W2.T` 若使用已经更新的 `W2`，就会把旧参数算出的 `dZ2` 与新参数混在一起，得到不一致的梯度。

**练习 4：** 预测类别可能没有变，但正确类别的概率变得更高，因此 Cross Entropy 下降而 Accuracy 不变。反过来，准确率不变也不保证 loss 一定下降。

**练习 5：** `model.probabilities` 是最近一次 `forward` 缓存的结果，仍对应更新前的参数。要看新参数的预测，必须重新执行 `model.forward(X)`。

**四个关键梯度及 shape（沿用第 2 节 `N=4, D=2, H=8, C=2`）：**

```text
dW2 = A1.T @ dZ2         (8, 4) @ (4, 2) -> (8, 2)
dA1 = dZ2 @ W2.T         (4, 2) @ (2, 8) -> (4, 8)
dZ1 = dA1 * (Z1 > 0)     (4, 8) * (4, 8) -> (4, 8)
dW1 = X.T @ dZ1          (2, 4) @ (4, 8) -> (2, 8)
```

**XOR 运行记录：** 使用 Day 6 的 `seed=42`、隐藏层宽度 8、学习率 `0.1`、训练 3000 轮。初始 loss `1.01177835`、accuracy `0.75`；最终重新 forward 后 loss `0.00327397`、accuracy `1.00`，预测 `[0, 1, 1, 0]`，与标签一致。这是训练集上的结果，不代表已检验泛化能力。

**学习率对比：** 保持上述模型、数据、随机种子和轮数不变，只更换学习率。`0.01` 的最终 loss 为 `0.08496311`；`0.1` 为 `0.00327397`；`0.5` 为 `0.00053908`，三者在这 4 个训练样本上的 accuracy 均为 `1.00`。在这个实验里，`0.5` 下降最快；这不意味着学习率越大越好，换模型、数据或学习率可能出现震荡或发散。

**日志 loss 与最终 loss：** `train()` 每轮先记录 loss，后更新参数。`loss_history[-1] = 0.00327542` 是第 3000 次更新之前的 loss；用最终参数再执行一次 forward，得到 `0.00327397`。四位小数显示时二者都约为 `0.0033`。

**一次训练的口头复述示例：** 用当前参数前向计算概率；根据标签计算平均 Cross Entropy；从输出层向前一层依次计算梯度，并核对梯度 shape；全部算完后按学习率更新 `W1`、`b1`、`W2`、`b2`；下一轮重新前向计算。
